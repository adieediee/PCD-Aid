# PCD Aid – rapid prototyp

Klikateľný prototyp webovej aplikácie pre diagnostiku primárnej ciliárnej dyskinézy (PCD) – diplomová práca, FIIT STU.
Všetky dáta sú fiktívne, AI je simulovaná metódou Wizard of Oz.

## Spustenie

```bash
cd app
npm install
npm run dev
```

Appka beží na http://localhost:5173. Rolu (pediater / histopatologička / PhD študentka) prepneš vpravo hore.

- `CLAUDE.md` – kontext projektu a stav prototypu
- `DESIGN.md` – design systém
